# Dataset Policy

Raw social-media datasets are not redistributed in this repository.

The primary experiments use transit-related Chinese social-media posts from Beijing, Shanghai, and Xiamen. Raw posts, user identifiers, profile information, coordinates, and other potentially identifying material are excluded.

The external English evaluation uses the Transit Tweet Data resource associated with *Learning About the Transit Passenger Experience from Microblogging Posts* (2025), DOI 10.32866/001c.140966.

Users should obtain datasets from authorized sources and comply with applicable licenses and terms.

Individual human-annotation response files are not distributed. Human judgments are used only for post-fit evaluation and do not enter model fitting or document inference.
