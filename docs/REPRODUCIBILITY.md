# Reproducibility and Command-Line Execution

This document describes the canonical command-line workflow for reproducing the released pipeline from the repository root in a **PowerShell terminal**, including the terminal integrated into PyCharm.

> **Important:** The final scientific pathway uses **Step 04R2, Step 05R2, and Step 06R2**. The older Step 04 and Step 06 routes are retained only for compatibility/audit and are **not** part of the canonical reproduction path. There is no canonical Step 05 route.

## 1. Requirements

- Python 3.10 or later.
- Stage-specific dependencies listed in the corresponding `requirements-step*.txt` files.
- Authorized local copies of the required datasets; raw datasets are not distributed with this repository.
- The locked EnCOT parent implementation used by Step 03.
- Outputs generated by prerequisite stages.

Locked EnCOT commit:

```text
8ac3592165cc7851676be2776b314eb6e44e9388
```

Raw datasets, individual annotator-response files, model checkpoints, private outputs, and local third-party checkouts are intentionally excluded from the public repository.

See [`DATASETS.md`](DATASETS.md) for dataset placement, integrity information, and release restrictions.

## 2. Open the repository in a PyCharm PowerShell terminal

All commands below must be executed from the repository root, i.e. the directory containing `main_v6.py`.

Example:

```powershell
Set-Location "C:\path\to\passenger-graph-refinement"
```

Confirm that the expected files are visible:

```powershell
Get-ChildItem
```

## 6. Required Step-13 → Step-10 evidence transfer

After Step 13 completes successfully, create the Step-10 external-evidence directory:

```powershell
New-Item -ItemType Directory -Force .\inputs\v6\step10\external | Out-Null
```

Copy the generated Step-13 evidence envelope:

```powershell
Copy-Item `
  .\outputs\v6\step13_external_generalization\v6_1_transit_tweet_temporal\copy_contents_to_inputs_v6_step10_external\* `
  .\inputs\v6\step10\external\ `
  -Force
```

Then rerun Step 10:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_step10.ps1
```

The final Step-10 pass requires the genuine human-evaluation evidence together with the validated Step-13 external-evidence envelope.

python .\main_v6.py --stage step5r2 --project-root . --config .\configs\v6\step05r2.yaml

python .\main_v6.py --stage step9   --project-root . --config .\configs\v6\step09.yaml
python .\main_v6.py --stage step10  --project-root . --config .\configs\v6\step10.yaml
python .\main_v6.py --stage step11  --project-root . --config .\configs\v6\step11.yaml
python .\main_v6.py --stage step11b --project-root . --config .\configs\v6\step11b.yaml

```powershell

```

```powershell

--encot-python "C:\path\to\python.exe"
```

Use these overrides only when the frozen configuration cannot resolve the intended local resource automatically.

## 12. Reproducibility scope

The repository provides the released implementation, frozen configurations, stage runners, tests, and documentation required to reconstruct the analysis when the user has authorized access to the required datasets and restricted human-evaluation inputs.

The release does not distribute raw social-media datasets, user identifiers, geographic coordinates, individual annotator responses, private model checkpoints, or restricted third-party archives.
