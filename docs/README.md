# Documentation

This directory contains the public documentation for the passenger-requirement discovery framework.

- [Dataset Documentation](DATASETS.md) — dataset statistics, access, privacy, local placement, and integrity information.
- [Reproducibility Guide](REPRODUCIBILITY.md) — complete command-line workflow and stage-by-stage reproduction instructions.
