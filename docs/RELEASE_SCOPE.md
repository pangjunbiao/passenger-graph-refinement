# Release Scope

This repository is a clean release staging copy for the research code associated
with:

**Likelihood-Coupled Graph-Prototype Refinement for Discovering Passenger
Requirements from Social Media**

The release is intentionally separated from the original experimental workspace.

## Included

- Python source code required by the research pipeline
- automated tests
- frozen stage configuration files
- canonical PowerShell stage runners
- dependency notes
- release and reproduction documentation

## Excluded

- raw or restricted research datasets
- social-media identifiers and coordinates
- individual human-annotation response files
- model checkpoints
- generated logs
- experiment output directories
- result ZIP archives
- local development environments
- local third-party checkouts

## Internal identifiers

Some implementation strings retain the historical internal identifier
`SC-HTM V6.1`. These identifiers are preserved where changing them could affect
reproducibility, serialized contracts, hashes, tests, or the interpretation of
frozen experimental artifacts.

The public repository title therefore does not require wholesale renaming of
internal experimental identifiers.

## Data availability

The code release and the redistribution of research data are separate matters.
Dataset access, licensing, privacy, and reproduction instructions will be stated
in the finalized data documentation before public release.
