# Input Data

Raw research datasets are **not distributed in this repository**.

The internal passenger-requirement experiments use transit-related social-media
corpora whose redistribution status, access conditions, and privacy constraints
must be respected independently of this code release.

The external English replication uses the Transit Tweet Data resource associated
with the study *Learning About the Transit Passenger Experience from Microblogging
Posts* (2025). Users should obtain any external dataset from its authorized source
and comply with the corresponding terms of use and license.

Do not commit raw posts, user identifiers, coordinates, profile information,
annotation-response files, or other potentially identifying source material to
this directory.

Where a pipeline stage requires restricted or separately obtained input data,
provide the required path locally as described in `docs/DATASETS.md` and
`docs/REPRODUCIBILITY.md` once those release documents are finalized.
